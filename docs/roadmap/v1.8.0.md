# v1.8.0 Delivered Scope

**Theme:** Extensible Connector Platform.

Delivered: stable connector contract, capability catalog, typed retryable/permanent failures, legacy Kafka/HTTP compatibility, native connector routing schema, Kafka and HTTP JSON connectors, OTLP/HTTP JSON ingest/export, Prometheus Remote Write, Splunk HEC, Datadog Logs, environment-backed credentials, runtime connector heartbeats/API/dashboard/metrics, connector CLI commands, migration 015, protocol/security tests, and ADRs 0043-0045.

Deliberately excluded: arbitrary native plugin loading, unsigned external code execution, OTLP protobuf ingestion, and automatic promotion of every telemetry tag to a Prometheus label.

v1.9 should focus on Scale, HA & Operational Proof with reproducible outage, recovery, backup/restore, rolling-upgrade, and benchmark artifacts.
