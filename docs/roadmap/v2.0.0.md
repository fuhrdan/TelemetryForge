# v2.0.0 Delivered Scope

**Theme:** Evidence-First Intelligent Telemetry Control Plane.

## Delivered

- deterministic Evidence-First Investigator
- exact Evidence Graph edge/node citations
- explicit `insufficient_evidence`, `mixed_evidence`, and `evidence_supported` states
- contradictory-evidence visibility
- tenant-scoped investigation snapshots
- incident comparison with reproducible weighted similarity
- cited matching node IDs for comparisons
- advisory shadow-policy recommendations backed by recorded Cost Simulation
- optional completed Incident Replay citation and quarantine warning
- mandatory human approval/lifecycle promotion boundary
- investigation/compare/history HTTP APIs
- `telemetryctl intelligence investigate/compare/list`
- dashboard Evidence-First Investigator surface
- migration `017_intelligent_control_plane.sql`
- human-readable intelligence documentation and ADRs 0049-0051

## Deliberately not implemented

- autonomous production policy mutation
- uncited generated root-cause narratives
- external-model calls in the deterministic investigation path
- hidden chain-of-thought or unverifiable reasoning artifacts
- fabricated certainty when captured evidence is weak
- treating incident similarity as shared root cause

## Product position

By v2.0 TelemetryForge controls what telemetry is retained and routed, preserves incident evidence before lossy decisions, records operational changes and proof, safely replays incidents, models cost/cardinality impact, and synthesizes those recorded artifacts into a cited operator investigation.
