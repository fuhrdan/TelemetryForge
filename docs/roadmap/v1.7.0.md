## Cumulative correction

The actual worker pipeline is now aligned with the intended v1.4 contract:

```text
Flight Recorder
 -> Normalizer
 -> Schema Intelligence
 -> Change Intelligence
 -> Adaptive Shaping
 -> Cardinality Firewall
 -> Persistence
 -> Routing outbox
 -> Incident Detector
```

This ensures full evidence/schema/change capture occurs before lossy shaping,
and cardinality decisions operate on the shaped event that will proceed toward
persistence/routing.
