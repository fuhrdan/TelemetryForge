# v2.6.0 Delivered Scope

TelemetryForge v2.6.0 adds a measured high-performance replay path while preserving the durability and audit boundaries delivered in v2.1-v2.5.

Delivered:

- bounded edge replay batching;
- optional batch publishing contract with per-item results;
- asynchronous Kafka batch produce with pooled JSON buffers;
- local-owner mesh batch preservation with safe failover fallback;
- pooled WAL scan buffers;
- bounded lock-free MPMC ring primitive;
- fast-path diagnostics in `/edge/status`;
- dependency-free unit/race tests for the new primitives;
- repeatable `-benchmem` benchmark evidence and Operational Proof integration;
- CI benchmark artifact capture without hard-coded vanity performance thresholds.

The release intentionally does not claim zero allocations across the full product, a fixed events-per-second ceiling, or universal latency numbers. Those depend on payloads, durability settings, Kafka, storage, hardware, topology, and workload shape.
