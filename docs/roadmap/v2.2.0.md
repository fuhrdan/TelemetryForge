# v2.2.0 Delivered Scope

TelemetryForge v2.2.0 extends Durable Edge from a single durable disk to an explicit replicated acceptance boundary.

## Delivered

- synchronous edge-to-edge durable replication;
- receiver-side fsynced replica logs;
- idempotent replica retry by origin edge sequence;
- conflicting-sequence rejection;
- `local`, `regional`, `cross-region`, and `cross-cloud` durability classes;
- configurable quorum counting the local durable copy;
- availability-zone, region, and cloud failure-domain evaluation;
- non-local quorum readiness checks;
- replication-before-Kafka replay/recovery ordering;
- separate bearer-token boundary for internal replication traffic;
- bounded replica capacity with durable release-through checkpoints and compaction after downstream commit;
- replication state in `/edge/status`;
- three-edge Docker Compose regional quorum example;
- Kubernetes configuration hooks for replica storage/durability mode;
- unit/integration-style HTTP replication tests;
- operational proof harness for quorum and replica recovery behavior;
- ADR 0053 and operator documentation.

## Deliberately not claimed

- consensus membership or automatic leader election;
- automatic promotion of a replica log into a new origin;
- automatic WAN/global route selection;
- cryptographically signed lineage;
- mathematically proven zero loss;
- sub-millisecond cross-region/cloud convergence.
