# v2.9.0 — Multi-Cloud Proof

**Status:** Delivered.

## Scope

- deterministic AWS/GCP/Azure/bare-metal failure-domain accounting model;
- cloud outage, region partition, disk/capacity pressure, ambiguous network acknowledgement, and cascading outage schedules;
- zero-unaccounted-event invariant for accepted telemetry;
- explicit rejection-before-acceptance when durability quorum is unavailable;
- machine-readable `multicloudcheck` report;
- `.tfproof.json` Operational Proof integration;
- destructive local Compose failover suite using logical cloud labels;
- GCP GKE and Azure AKS Terraform foundations alongside the existing AWS EKS foundation;
- ADR 0060 defining the boundary between model evidence and real-provider chaos.

## Non-claims

The checked fault model is not evidence that hosted CI caused a real cloud-provider outage. The local Compose suite is not physically multi-cloud. Real-provider recovery, latency, availability, and durability claims require independent evidence from the actual target infrastructure.
