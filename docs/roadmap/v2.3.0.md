# v2.3.0 Delivered Scope

TelemetryForge v2.3.0 adds a global edge routing mesh above the Durable Edge and Replicated Durability layers.

## Delivered

- authenticated edge/relay topology advertisements;
- active peer health probing with stale-state rejection;
- cloud/region/zone failure-domain metadata;
- WAL-pressure and draining-state route exclusion;
- deterministic rendezvous-hash ownership;
- `locality` and `global` route policies;
- automatic ordered-candidate failover;
- terminal peer forwarding with loop prevention;
- public route inspection through `/edge/route`;
- mesh state in `/edge/status`;
- three-edge active-active Docker Compose topology;
- Kubernetes configuration/secrets surface;
- route/failover proof harness;
- ADR 0054 and operator documentation.

## Semantics

v2.3 does not change the v2.2 acceptance boundary. An event is still accepted only after its configured durability contract succeeds. Mesh routing occurs during downstream replay, and the origin WAL is checkpointed only after local or remote terminal delivery succeeds.

## Deferred

- dynamic cloud/service discovery;
- gossip-based topology distribution;
- cryptographically signed topology advertisements;
- WAN latency prediction;
- cost-aware inter-cloud route optimization;
- autonomous ML routing.
