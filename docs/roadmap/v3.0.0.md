# v3.0.0 — Global Edge Fabric

## Goal

Consolidate the v2.1-v2.9 edge milestones into one production-facing Global Edge Fabric contract without rewriting the proven data paths.

## Delivered scope

- unified `ready` / `degraded` / `not_ready` fabric evaluation;
- separate durable-acceptance, downstream-delivery, and cryptographic-audit readiness;
- `GET /edge/fabric/status` runtime endpoint;
- dependency-free `telemetryforge-fabriccheck` release-contract checker;
- fail-closed quorum, WAL-capacity, lineage, and required-eBPF semantics;
- degraded-but-accepting behavior for downstream partitions;
- Global Edge Fabric operational proof artifact;
- v3 compatibility/upgrade guidance and consolidated architecture documentation;
- current-version alignment across services, dashboard, CI, and Kubernetes manifests.

## Preserved contracts

v3.0 intentionally preserves the established v2.x formats and boundaries:

- WAL v1/v2 read compatibility remains unchanged;
- `.tfincident` and `.tfproof.json` formats are not replaced;
- public ingestion APIs remain under `/api/v1`;
- internal replication and mesh endpoints remain versioned under `/internal/v1`;
- durability remains at-least-once across ambiguous delivery failures;
- policy/autonomy remains bounded and does not bypass protected telemetry rules.

## Non-goals

- exactly-once end-to-end delivery;
- consensus/blockchain infrastructure;
- universal zero-loss claims outside stated durability assumptions;
- autonomous production configuration promotion;
- arbitrary privileged eBPF payload inspection.
