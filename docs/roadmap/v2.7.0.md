# v2.7.0 Delivered Scope

TelemetryForge v2.7.0 adds a shadow-first autonomous control loop without weakening the safety boundaries delivered in v2.1-v2.6.

## Delivered

- bounded near-term worker queue-pressure forecasting;
- `off`, `shadow`, and explicit opt-in `auto` modes;
- temporary non-protected sampling multipliers;
- protected-telemetry preservation and existing shaping minimums;
- fsync-before-apply local action audit log;
- automatic rollback on pressure recovery, TTL, error regression, or latency regression;
- cooldown after terminal action transitions;
- retry-stable shaping decisions carrying the multiplier used;
- `/autonomy/status` worker-admin endpoint;
- capability-free WebAssembly manifest/module validation and host backend contract;
- executable autonomy checker and `.tfproof.json` operational-proof scenario;
- ADR 0058.

## Explicit non-goals

v2.7.0 does not claim general AI root cause analysis, globally coordinated multi-worker control, autonomous lifecycle promotion, arbitrary schema rewriting, or a bundled WebAssembly execution engine. Those require additional distributed-control and sandbox evidence.
