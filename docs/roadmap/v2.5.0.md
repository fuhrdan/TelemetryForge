# v2.5.0 Delivered Scope

TelemetryForge v2.5.0 adds executable formal safety models around the durability and audit boundaries introduced in v2.1-v2.4.

## Delivered

- TLA+ models for durable ingest, replicated durability, mesh failover, and cryptographic lineage;
- finite TLC model configurations for every specification;
- dependency-free Go bounded state-space checker;
- machine-readable formal-check report format;
- adversarial protocol action-schedule fuzz target;
- dedicated CI formal-verification job with pinned TLA+ tooling;
- SANY syntax validation before TLC model checking;
- `formal-verification` operational proof scenario;
- `.tfproof.json` evidence integration;
- ADR 0056 documenting the proof boundary;
- formal verification documentation and testing guidance.

## Claim boundary

The release proves bounded safety invariants of the abstract protocol models. It does not claim a proof of arbitrary network liveness, exactly-once delivery, hardware infallibility, or bug-free implementation code.
