# v1.5.0 Delivered Scope

**Theme:** Portable Incident Archive and offline investigation.

## Delivered

- versioned `.tfincident` ZIP format
- human-readable standard file layout
- per-member SHA-256 integrity manifest
- complete-file SHA-256 CLI output
- strict manifest/member/count verification
- path-traversal and duplicate-member rejection
- bounded ZIP/event parsing
- frozen-event `captured_at` preservation
- Evidence Graph snapshot
- incident-related schema history/drift snapshot
- replay history snapshot
- cost-simulation snapshot
- exact validated policy/shaping/routing configuration snapshots
- AES-256-GCM outer encryption using explicit 256-bit key files
- `telemetryctl incident export`
- `telemetryctl incident verify`
- `telemetryctl incident inspect`
- `telemetryctl incident report`
- `telemetryctl incident import`
- explicit tenant-remap acknowledgement
- no-overwrite incident import
- durable import provenance
- tenant-scoped archive-import history API/dashboard
- self-contained offline HTML report
- integration test for export/verify/remap/import/audit lifecycle

## Deliberately not implemented

v1.5 does not:

- accept human passwords and invent a password KDF;
- automatically upload archives to object storage;
- automatically apply archived configuration on import;
- replay imported evidence through production ingestion;
- provide a public-key/signature PKI;
- claim an unencrypted archive is safe to share;
- import historical replay/cost rows into live operational history.

Those decisions keep the format portable and the import path non-destructive.
