# v2.1.0 Delivered Scope

TelemetryForge v2.1.0 begins the Global Edge Fabric roadmap with a local durable acceptance boundary.

Delivered: `telemetryforge-edge`; segmented WAL; fsync-before-acceptance; CRC32 plus event SHA-256 integrity; global edge and tenant/source sequences; atomic delivery checkpoint; ordered Kafka replay; bounded retry; WAL-capacity backpressure; delivered-segment compaction; torn-tail recovery; fail-closed completed-frame corruption; `/edge/status`; Docker Compose persistence; Kubernetes StatefulSet/PVC; tests; `.tfproof.json` crash/recovery harness; ADR 0052.

Explicit non-goals: cross-edge replication, cloud-aware routing, formal verification, Merkle lineage, eBPF collection, and autonomous ML control.
