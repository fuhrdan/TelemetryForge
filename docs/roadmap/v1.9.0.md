## Evidence rule

v1.9 does not publish a capacity, recovery, availability, or zero-downtime
number unless a reproducible proof run actually measured it.

## v2.0 handoff

v2.0 can build the Evidence-First Intelligent Telemetry Control Plane on top of
this proof layer: recommendations and incident conclusions can cite archived
incidents, change intelligence, replay/cost results, and operational proof
instead of generating unsupported confidence.
