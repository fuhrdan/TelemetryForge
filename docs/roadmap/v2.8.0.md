# v2.8.0 Delivered Scope

TelemetryForge v2.8.0 adds optional Linux eBPF edge collection without moving durability, routing, policy, or autonomous-control decisions into the kernel.

## Delivered

- dependency-free Linux tracepoint eBPF counter programs;
- process-exec, socket-connect, and TCP-retransmit aggregate counters;
- BPF array-map polling with monotonic delta accounting;
- durable edge WAL/quorum handoff with local-persistence receipts;
- retry of deltas rejected before local persistence;
- no duplicate collector retry after local WAL persistence;
- optional vs required startup behavior;
- `/edge/ebpf/status` and eBPF state in `/edge/status`;
- `telemetryforge-ebpfcheck` static and target-node live checks;
- explicit Kubernetes capability/tracefs overlay;
- executable `.tfproof.json` collector proof;
- ADR 0059.

## Explicit non-goals

v2.8.0 does not capture packet bodies, DNS names, command arguments, process environments, or arbitrary syscall data. It does not claim universal support across Linux kernels/container policies, and it does not place routing or autonomous policy logic inside BPF programs.
