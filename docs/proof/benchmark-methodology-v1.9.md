# v1.9 Benchmark Methodology

Operational proof separates **execution evidence** from **interpretation**.

For every benchmark intended for publication, preserve:

1. exact TelemetryForge commit;
2. k6 scenario/config fingerprint;
3. Docker/Kubernetes/Terraform configuration fingerprint as applicable;
4. host/runner description;
5. raw k6 output;
6. `.tfproof.json` whole-file SHA-256;
7. any thresholds used to determine pass/fail.

Do not compare two benchmark runs if their load shape, topology, persistence,
connector set, or machine resources materially differ without saying so.

The repository intentionally contains no fabricated "250k events/minute" or
similar number. Results belong in reviewed proof artifacts generated by the
harness on known hardware.
