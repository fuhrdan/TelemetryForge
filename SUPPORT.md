# Support

TelemetryForge is currently a pre-1.0 engineering/portfolio project.

For normal problems, open a GitHub issue using the bug-report template and
include:

- TelemetryForge version or commit
- operating system
- Docker / Go / Node versions as relevant
- command that failed
- expected behavior
- actual error output
- minimal reproduction steps

Before opening an issue, check
[`docs/operations/troubleshooting.md`](docs/operations/troubleshooting.md).

For security-sensitive issues, follow [SECURITY.md](SECURITY.md) and avoid
posting exploit details or real telemetry publicly.
